# Document Production Conventions

## LaTeX

- Default document class: `memoir`
- Compile with `xelatex`
- Templates location: `/Users/local/latex-templates/`
- Projects location: `/Users/local/latex/`
- Use the `/latex` skill for detailed formatting and templates

## Microsoft Office (via MCP Servers)

- **Word:** Use `word-document-server` MCP
- **PowerPoint:** Use `ppt` MCP
- **Excel:** Use `excel` MCP

## Format Selection

- **Formal / academic / print:** LaTeX
- **Business collaboration / stakeholder delivery:** Word/PowerPoint
- **Data analysis / reporting:** Excel
- **Internal notes / knowledge base:** Markdown (Obsidian)
