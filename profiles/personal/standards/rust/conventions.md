# Rust Conventions

## Version & Edition

- Rust 1.92.0, Edition 2024
- Projects location: `/Users/local/rust/`

## When to Use Rust

- Complex tasks where local execution speed matters
- System-level tools and utilities
- When in `/Users/local/rust/` directory

## Project Setup

- Use `cargo` for project management
- Follow Edition 2024 idioms and patterns
- Use the `/rust` skill for version details and migration guidance
